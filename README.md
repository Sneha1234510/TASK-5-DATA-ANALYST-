# Task 5 — Exploratory Data Analysis (EDA)

## Files
- `Task5_Titanic_EDA.ipynb` — Jupyter Notebook with the complete EDA workflow.
- `Task5_EDA_Report.pdf` — PDF report describing the objective, methods, observations, and conclusion.
- `requirements.txt` — Python packages needed to run the notebook.

## Dataset
The notebook downloads the Titanic training CSV from:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

Internet access is required when running the first data-loading cell. The dataset is not redistributed in this package.

## Run
1. Install Python and Jupyter Notebook (or use Google Colab).
2. Install dependencies: `pip install -r requirements.txt`
3. Open `Task5_Titanic_EDA.ipynb`.
4. Run all cells from top to bottom.
5. Review the generated charts and outputs. Add your own observations if your mentor expects personalized interpretation.
6. Upload this folder to a new GitHub repository as requested in the task instructions.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn.

## Note
The PDF gives broad findings commonly observed in the standard Titanic training dataset. Run the notebook and use its actual output if you need exact values for your copy of the dataset.
